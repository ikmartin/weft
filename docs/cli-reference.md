`weft [OPTIONS] COMMAND [ARGS]...`

A library of mathematical results: crawl, extract, link, serve.

|---|---|

## `weft extract`

`weft extract [OPTIONS] [IDENT]...`

Read the named works' LaTeX sources into statements and proofs; with no IDENT, every version that has a source and no results.

| option | description |
|---|---|
| `--all` | Re-extract versions that already have results. |
| `--proofs` | Keep each result's proof, or keep none of them. |
| `--compile` | Run latexmk for real numbers where no .aux is beside the source. |
| `--json` |  |
| `--corpus` `PATH` | The corpus root (default: found by walking up). |
